# 🤖 Conversational Knowledge Bot - Complete Project

## 📖 Overview

This is a **FREE AI-powered conversational chatbot** that uses Google Gemini API. The bot can perform calculations, answer questions, remember conversations, and provide intelligent responses - all without spending any money!

## ✨ Features

### 🆓 Two Modes Available:

1. **Simple Mode** (No API Required)
   - ✅ Works instantly without any setup
   - ✅ Calculator functionality
   - ✅ Current time display
   - ✅ Basic knowledge base
   - ✅ 100% FREE

2. **Gemini AI Mode** (FREE Google API)
   - ✅ Full AI conversations
   - ✅ Creative writing (poems, stories)
   - ✅ Code explanations
   - ✅ Learning assistance
   - ✅ Natural language understanding
   - ✅ Unlimited free usage

## 🚀 Quick Start (3 Steps)

### Step 1: Check Python Installation
```bash
python --version
```
Should show Python 3.6 or higher.

### Step 2: Get FREE Gemini API Key (Optional but Recommended)
1. Visit: https://ai.google.dev/
2. Click "Get API Key"
3. Sign in with Google
4. Create API key
5. Copy and save it

### Step 3: Run the Bot
```bash
# Windows
python free_bot.py

# Mac/Linux
python3 free_bot.py
```

Choose your mode and start chatting! 🎉

## 💻 Installation Options

### Option 1: Simple Mode (No Installation!)
```bash
python free_bot.py
# Choose option 1 - Works immediately!
```

### Option 2: Gemini AI Mode (Recommended)
```bash
pip install google-generativeai
python free_bot.py
# Choose option 2
```

### Option 3: Advanced LangChain Mode
```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY='your-key'
python conversational_bot.py
```

## 🆘 Quick Troubleshooting

| Problem | Solution |

| Python not found | Install from python.org |
| pip not recognized | Use `python -m pip install` |
| API key invalid | Check for spaces, generate new key |
| Module not found | Run `pip install google-generativeai` |
